# متابعة الدوام والانضباط — مدرسة خالد بن الوليد الثانوية للبنين

تطبيق ويب يعمل على أندرويد وآيفون وويندوز، يحفظ بياناته في جدول Google يملكه مساعد المدير.

- **هذا المستودع عام**: لا يحتوي أي اسم طالب أو رقم هاتف أو رمز دخول.
- الأسماء والرصد في جدول Google خاص. أرقام أولياء الأمور على جهاز المستخدم فقط.
- `gas/code.gs`: كود الخادم الذي يُلصق في Apps Script داخل الجدول.
- `config.js`: رابط السكربت فقط (`/exec`). إن كان فارغاً يعمل التطبيق بوضع تجريبي ببيانات وهمية.

## تشغيل الخادم (مرة واحدة)
1. ارفع ملف قاعدة البيانات الخاص إلى Google Drive، افتحه، ثم **File ← Save as Google Sheets**، واحذف ملف xlsx الأصلي من Drive.
2. في الجدول الجديد: **Extensions ← Apps Script**، امسح المحتوى والصق `gas/code.gs`، ثم احفظ.
3. اختر الدالة `setup` واضغط **Run**، ووافق على الصلاحيات. يظهر في السجل عدد الطلاب والشعب والأيام والمستخدمين.
4. **Deploy ← New deployment ← Web app**: Execute as: **Me**، Who has access: **Anyone**. انسخ الرابط المنتهي بـ `/exec`.

## رموز الدخول
في ورقة **المستخدمون**: الاسم، رمز الدخول (8 خانات على الأقل)، فعّال (TRUE/FALSE). لإيقاف شخص اجعلها FALSE.

## تحديث كود الخادم لاحقاً
الصق الكود الجديد ثم **Deploy ← Manage deployments ← ✎ ← Version: New version ← Deploy** (الرابط لا يتغير).
